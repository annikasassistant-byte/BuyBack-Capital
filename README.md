# BuyBack Capital

Frontend-only Next.js platform for BuyBack Capital private-debt investment.

## Branding

- Primary colors: purple + white (BuyBack branding)
- Design reference: [working-capital-financing.lovable.app](https://working-capital-financing.lovable.app/)

## Pages

- `/` – Public landing page (share this with prospects)
- `/dashboard` – Investor area with direct link/share actions for the landing page

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide icons

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the next free port).

## Scripts

- `npm run dev` – local development
- `npm run build` – production build
- `npm run start` – serve production build
